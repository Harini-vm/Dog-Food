API reference

Base URL /api/v1. Authenticate with Authorization: Bearer <token> (create one on your account page). Errors are JSON: {"error": "code", "message": "..."}. A wrong token is always 401, a missing permission 403. The raw specification is /api/openapi.json (OpenAPI 3). Organizer pages under /organize/… also accept JSON with a bearer token.
